# 🌕 中秋餐會座位預約系統

| 檔案 | 用途 |
|---|---|
| `index.html` | 前端表單（同事點進去用的頁面），單一檔案、無外部相依 |
| `Code.gs` | Google Apps Script 後端，資料存進 Google 試算表，含防超賣鎖 |

## ⚠️ 先看：座位數不夠

| 桌型 | 張數 | 小計 |
|---|---:|---:|
| 4 人桌 | 7 | 28 |
| 6 人桌 | 9 | 54 |
| 8 人桌 | 1 | 8 |
| **合計** | **17** | **90 席** |

報名 **92 人**，**缺 2 席**。開放登記前請先決定：

- **加椅**：挑兩張 6 人桌坐 7 人 → 把 `TABLE_CONFIG` 拆成 `{prefix:'乙', size:7, count:2}` 和 `{prefix:'乙B', size:6, count:7}`
- **加桌**：跟餐廳多要一張 4 人桌 → `count: 7` 改成 `8`

`index.html` 和 `Code.gs` **兩邊的 `TABLE_CONFIG` 要改成一樣**，否則前端顯示的空位數會和後端實際容量對不上。

## 要不要資料庫？

**不用。** 但也不能只用一個 Excel 檔。

你的需求裡有一句是關鍵：「**被預訂就要扣掉數量，讓其他人無法預約**」。這叫並行控制——兩個人同時搶最後一個位子，系統必須只讓一個人成功。共用資料夾裡的 `.xlsx` 做不到（後存檔的人會直接覆蓋前一個人）。

**Google 試算表 + Apps Script** 剛好兩全：

- 資料就是一張試算表，福委隨時可以開來看、排序、匯出 Excel ✅
- Apps Script 的 `LockService` 提供真正的互斥鎖，不會超賣 ✅
- 免費、不用主機、不用維運 ✅

92 人的規模，這個組合綽綽有餘。

## 部署步驟（約 10 分鐘）

### 1. 建立試算表與後端

1. 開 [sheets.new](https://sheets.new) 建立空白試算表，命名為「中秋餐會報名」
2. 選單 **擴充功能 → Apps Script**
3. 把編輯器裡原本的 `function myFunction() {}` 全部刪掉，貼上 `Code.gs` 的完整內容
4. 存檔（Ctrl+S）

### 2. 部署成網頁應用程式

1. 右上角 **部署 → 新增部署作業**
2. 齒輪圖示 → 選 **網頁應用程式**
3. 設定：
   - 執行身分：**我**
   - 誰可以存取：**任何人**（若只給公司內部用，可選「{貴公司網域} 的所有人」，但同事必須先登入公司 Google 帳號）
4. 按 **部署**，第一次會要求授權 → 允許
5. 複製產生的網址（`https://script.google.com/macros/s/AKfy.../exec`）

### 3. 接上前端

打開 `index.html`，找到第 300 行左右的設定區：

```js
const API_URL = '';   // ← 把剛剛複製的 /exec 網址貼進這裡的引號中
```

### 4. 把頁面放上網

`index.html` 是單一檔案，任選一種：

- **最快**：到 [app.netlify.com/drop](https://app.netlify.com/drop) 把檔案拖進去，30 秒拿到公開網址
- **GitHub Pages**：上傳到 repo → Settings → Pages → 啟用
- **公司內網**：丟到任何能放靜態檔的地方即可

> 直接雙擊用 `file://` 開啟也能跑，但部分瀏覽器會擋跨網域請求，正式使用請用上面任一種方式架起來。

### 5. 驗收

把網址丟到群組前，自己先測一遍：

1. 登記 1 人 → 該桌空位少 1 ✅
2. 用**另一台裝置**開同一個網址 → 看得到剛剛那筆 ✅
3. 試著把某張 4 人桌塞第 5 個人 → 應被擋下 ✅
4. 用同一個工號登記兩次 → 應被擋下 ✅
5. 用預約碼取消 → 空位回補 ✅

## 功能對照

| 你的需求 | 實作 |
|---|---|
| 點選要幾人桌 | 上方「4 人桌 / 6 人桌 / 8 人桌 / 尚有空位」篩選鈕 |
| 輸入自己的名字 | 卡片上「登記這桌」→ 填姓名 + 工號 + 餐別 |
| 一人預訂整桌 | 空桌才會出現「包下整桌」選項，需填滿全部人的姓名與工號 |
| 被預訂就扣掉數量 | 後端在鎖裡重新計算容量，額滿的桌子按鈕變成「額滿」且不可點 |
| 顯示剩下幾個名額 | 每張卡片右上角徽章 + 座位圓點圖示 |
| 交由福委安排 | 右上角「🎲 交由福委安排」，登記進待安排名單 |

另外附贈：

- **預約碼**：每次登記產生一組 6 碼，用來自助取消（避免亂刪別人的）
- **工號防重複**：同一個工號不能登記兩次
- **餐別統計**：頁面上即時顯示葷/素/其他人數，並和報名數（65 / 11 / 16）對照；素食者姓名會標 🌱，方便排在同桌
- **CSV 匯出**：福委專區一鍵下載，含 BOM，Excel 開啟不亂碼
- **座位總表**：試算表選單「🌕 餐會工具 → 產生座位總表」，自動整理每桌人數、餐別、名單
- **自動同步**：每 20 秒重抓一次，兩人同時搶同一桌時會提示「只剩 N 個位子」並刷新畫面

## 常見狀況

**改了 `Code.gs` 之後前端沒反應**
Apps Script 每次改完要重新部署：**部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**。網址不會變。

**同事說「無法連線到後端」**
八成是部署時「誰可以存取」沒設成「任何人」。回到管理部署作業改設定。

**想先關閉登記**
在 `Code.gs` 的 `book_()` 開頭加一行：
```js
throw new Error('登記已截止，如需異動請洽福委');
```
重新部署即可。頁面仍可瀏覽，但送不出新登記。

**想手動調整座位**
直接在試算表裡改「桌號」欄位就好，前端 20 秒內會自動同步。這也是把「待福委安排」的人分配到各桌的做法。

## 未設定 API_URL 時？

頁面會進入**單機示範模式**，資料存在瀏覽器的 localStorage，換裝置就看不到。這個模式只適合自己先試玩流程，正式開放前一定要完成第 2、3 步。
